# Michio CeiiAslii — Portfolio

Portfolio personal untuk Michio CeiiAslii, Network, Systems & Software. Dibangun menggunakan React, Vite, Tailwind CSS, dan Lucide icons.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Vite akan menampilkan URL lokal di terminal. Untuk mengakses dari perangkat lain dalam jaringan yang sama, server sudah dikonfigurasi untuk bind ke `0.0.0.0`.

## Pemeriksaan

```bash
npm run lint
npm run build
node scripts/portfolio-sanity.mjs
```

## Build / preview produksi

```bash
npm run build
npm run preview
```

Konten utama berada di `src/data/portfolio.js`; susunan halaman di `src/App.jsx`; komponen di `src/components/`.
